## ⭐ Featured Work

### 🏙️ Acrelix: Premium Real-Estate Platform for Delhi NCR
`🔒 Private · Client project`

A full-stack property platform for a Delhi NCR real-estate firm. It covers buyers, sellers, investors and agents in one product.

- **20+ pages**: property search, new developments, markets, neighbourhoods and neighbourhood guides, investor and concierge services, an agent directory, offices, and a mortgage calculator.
- **Interactive property map** built with Leaflet, with marker clustering and location pinning.
- **Serverless backend** on Firebase: Firestore, Data Connect (GraphQL), Storage, and Cloud Functions that route contact, sell-lead and concierge enquiries to the admin team by email in real time.
- **Admin dashboard**, plus hardened Firestore and Storage security rules.
- **Cinematic, scroll-driven UI** using GSAP, Lenis smooth scroll and Framer Motion, on a custom design system.

### 🛒 Freshobazaar: Brand Website for a Delhi Grocery Store
`🔒 Private · Client project` · **Live → [freshobazaar.com](https://freshobazaar.com)**

The digital storefront for a neighbourhood grocery brand. It's an editorial, motion-led landing experience that sends shoppers to the store's online shop.

- **Signature scroll sequences**: "The Aisle" (a pinned, mask-reveal walk through the store's categories) and a frame-by-frame pomegranate animation, built with GSAP ScrollTrigger using GPU-friendly transforms only.
- **Run like a studio project**: a written project brief, design-direction study, decision log, motion spec, design-token system, and QA and release checklists.
- **CI/CD**: Git-driven auto-deploys on Vercel, apex/www domain routing and a mobile-first performance budget.

### 🌾 Farm2Market AI: AI Sales Assistant for Taiwan's Local Farms
`🔒 Private · Prototype`

A bilingual (Traditional Chinese / English) AgriTech platform that connects Taiwan's local farms directly to buyers through a **LINE-based AI sales and marketing assistant**.

- A **farmer portal** with authenticated, protected routes, a sales dashboard with charts, and media and widget management.
- A **marketplace** with an interactive map of partner farm stores.
- Built on React and TypeScript, using TanStack Query, Recharts and react-leaflet, with browser-aware i18n.

| Project | What it does | Stack |
|---|---|---|
| **[ASL Fingerspelling Recognition](https://github.com/aditya-ydvv/ASL-Fingerspelling-Recognition-Project)** | An end-to-end **Transformer** that translates American Sign Language fingerspelling from video into text. MediaPipe hand-landmark extraction feeds a TFRecord pipeline, and the trained model is exported to **TensorFlow Lite** for on-device inference. Trained on Google's ASL Fingerspelling dataset (Kaggle). | TensorFlow · Keras · MediaPipe · TFLite |

Fine-tuning and evaluation are in progress. | Python · NLTK · indic-transliteration · Gemma 2 |

## 🔧 Hardware & Embedded

**[Alternative Controller for Sim Racing](https://github.com/aditya-ydvv/Alternative-Controller-For-Simulation-Racing)**: a custom-built racing rig that the PC recognises as a native USB gamepad.
- A 3D-printed steering wheel with rotary-encoder precision.
- An arcade joystick re-engineered as an **H-pattern gear shifter**, and a spring-loaded 3D-printed throttle pedal.
- **Voice-activated braking**: shout or blow into the sound sensor to brake.
- Arduino Nano firmware (C++, HID Gamepad), with all CAD files open-sourced.
